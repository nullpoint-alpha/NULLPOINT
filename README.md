# NULLPOINT

Turn a simple team into an unstoppable force and crush waves of monsters in this sci-fi PvE autobattler roguelike. No two runs feel the same as you discover countless combinations and synergies. Seal the rifts at your own pace and uncover what tore them open.

Currently in **closed alpha**.

**Download:** [latest release](../../releases)

## Status

Build `0.4.4` · win64 · pre-1.0.

## Requirements

- Windows 10/11 (x64)
- DirectX 11 capable GPU
- ~250 MB free disk

## Running

1. Download the zip from Releases and unzip anywhere.
2. Run `Nullpoint-alpha.exe`.
3. Windows will probably warn that the binary isn't commonly downloaded — it's
   unsigned at this point in development. Choose **More info → Run anyway**.
4. Have fun!

## Known issues

- Loader may halt partway with an `E_ASSET_MOUNT` fault and fall back to software
  rendering on machines with a cold shader cache.
- Audio device probing can stall for a few seconds.
- Balance is untuned past campaign node 4.
- Placeholder art throughout.

Please mail `alpha@nullpoint.is-a.dev` with any feedback or any issues you encounter! Include crash reports if possible.
